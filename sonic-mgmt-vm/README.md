# SONiC Management VM Topology

This directory contains a VM-based SONiC testing environment using Containerlab with sonic-vm (Virtual Machine) nodes instead of sonic-vs (container) nodes.

## Directory Structure

```
sonic-mgmt-vm/
├── README.md                          # This file
├── SONIC_VM_TOPOLOGY.md              # Detailed guide and documentation
├── QUICKSTART.md                     # Quick start guide
├── topology/
│   ├── t1-small-vm.clab.yml         # Main topology file (VM-based)
│   └── clab-t1-small-vm/            # Generated by containerlab
├── configs/
│   ├── sonic-dut/                   # DUT configuration
│   ├── t0/                          # T0 neighbor configuration
│   ├── t2/                          # T2 neighbor configuration
│   └── ptf/                         # PTF configuration
├── scripts/
│   ├── deploy_config.sh             # Deploy configuration files
│   └── verify_topology.sh           # Verify topology
└── monitoring/                       # Monitoring configurations
```

## Quick Start

### 1. Prerequisites

- KVM virtualization support on host
- sonic-vm Docker image
- 4+ CPU cores, 8+ GB RAM, 20+ GB disk space

### 2. Deploy Topology

```bash
cd ~/sonic-mgmt-vm
containerlab deploy -t topology/t1-small-vm.clab.yml
```

### 3. Wait for Boot

sonic-vm nodes take ~60 seconds to boot. Monitor progress:

```bash
docker ps | grep clab-t1-small-vm
```

### 4. Deploy Configuration

```bash
./scripts/deploy_config.sh
```

### 5. Run Tests

```bash
docker exec -it clab-t1-small-vm-sonic-mgmt bash
cd /sonic-mgmt/tests
python -m pytest bgp/test_bgp_fact.py -v \
  --testbed t1-small \
  --testbed_file /tmp/sonic-configs/testbed.yaml \
  --inventory /tmp/sonic-configs/inventory.ini \
  --host-pattern sonic-dut
```

## Key Differences from sonic-vs

| Feature | sonic-vs | sonic-vm |
|---------|----------|----------|
| Type | Container | Virtual Machine |
| Boot time | ~10 seconds | ~60 seconds |
| Resources | Low | High |
| Realism | Simplified | Production-like |
| KVM required | No | Yes |
